## 일일 뉴스 요약 화면

- 진입 URL: `/news/summary`. 기존 `/news` 화면과 독립된 페이지입니다.
- 페이지: `src/pages/news/summary.tsx`, 본문: `src/components/news-summary/`.
- API: `spring-back-end`의 공개 `GET /api/news/daily/summary/dates`, `GET /api/news/daily/summary?yyyymmdd=YYYYMMDD`.
- 개발 시 요약 API만 로컬 `3010`으로 프록시하며, 운영은 기존 백엔드 주소로 전달합니다.
- API는 기존 `news.daily.enabled=true` 설정에서 활성화됩니다. 로컬 실행은 백엔드 `docs/local-ssh-db.md`를 참고합니다.

### 날짜와 노출 순서

한국 시간 기준 오늘을 마지막에 둔 최근 7일을 표시합니다. 오늘은 최초 선택되고, 이전 날짜는 실제 뉴스가 있을 때만 선택할 수 있습니다. 날짜 목록은 가로 스크롤하며 선택된 날짜가 보이도록 이동합니다.

선택 날짜의 `news.NEWS_DAILY`에서 최대 `SEQ`만 조회하고 `DISP_ORD` 오름차순으로 표시합니다. 기존 최신 완료 시도 조회와는 목적이 달라 완료 이력 테이블과 조인하지 않습니다. 재조회는 캐시를 사용하지 않으며, 날짜 전환 시 이전 요청을 취소합니다.

### 읽음과 반응형

처음에는 검은색 카드로 표시합니다. 아래 방향 스크롤에서 카드 본문 하단이 화면 하단보다 32px 위를 지나면 해당 뉴스를 녹색 배경과 체크로 표시합니다. 페이지 최하단까지 남은 거리가 50px 이하면 선택 날짜의 모든 뉴스를 읽음 처리합니다.

읽음은 브라우저 `localStorage`의 `news-summary-read:v1`에 날짜·시퀀스별로 저장합니다. 새로고침과 날짜 재선택 시 복원하며, 같은 날짜의 새 시퀀스는 새 뉴스로 취급합니다. 기기·브라우저 간 동기화는 제공하지 않습니다. 저장소가 차단된 경우 현재 방문 동안만 유지합니다.

화면 중앙 너비는 PC `50vw`, 768~1199px 화면 `70vw`, 767px 이하 모바일 `100vw`입니다. 앱 내 웹뷰도 동일한 화면 너비 기준을 적용합니다.
